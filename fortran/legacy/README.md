Fortran Legacy Material
=======================

This directory contains historical Fortran code and data that are no longer
part of the active Merlino/GICForge workflow.

Active GICForge responsibilities are deliberately limited to Cartesian XYZ
input, GIC construction, optional B-matrix output, symmetry reporting, and
Gaussian input generation.

- `vibrational/`: old one-dimensional fitting, VCI/DVR and rate utilities.
  DVR orchestration and Gaussian scan post-processing are now Python workflow
  responsibilities.
